# CRM Kaizen Repository

This repository contains code samples, assets, and supporting files for weekly CRM Kaizen blogs.

## How to Contribute

1. Create a folder for your week: `kaizen_NNN_topic_name`
2. Add your kaizen blog files to that folder
3. Commit and push your changes

## Naming Convention
- Use format: `kaizen_[WEEK_NUMBER]_[TOPIC_NAME]`
- Use lowercase with underscores for spaces
- Keep topic names concise but descriptive
